# rug-tufting

this branch covers everything specific to the robotic rug tufting front.
same physical wall arm hardware as the wet paint work, but tufting comes first --
mechanically simpler, no wet medium physics, genuine commercial case.

## structure

- `docs/` -- concept, commercial case, projection mapping, generative source, prior art
- `hardware/` -- frame setup, projection mapping calibration, arm and gun interface
- `design/` -- generative source (p5 sketch), palette management, engine region tracing
- `milestones/` -- build checkpoints end to end

see also: `roadmap.md` on main for how this fits into the full build order.
