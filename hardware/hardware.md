# hardware -- embroidery

## machine overview

desktop footprint. pen-plotter scale. fits on a desk.
moves a needle in x/y across stabilizer backing clamped in a small hoop or frame.
needle pokes thread through the backing on each downstroke, building up stitches.

## dissolvable stabilizer

commercially available dissolvable stabilizer -- holds thread in place during stitching,
then dissolves completely in water when done. standard practice in embroidery.
no novel material science. cheap, widely available.

## mechanism

- needle descends, pokes thread through backing
- needle rises, thread catches and forms a stitch
- arm moves to next position
- repeat

no paint load. no resin viscosity. no yarn tension at scale.
mechanically the simplest needle-based mechanism in the project.

## key parameters

- needle depth -- how far the needle descends into the backing
- stitch length -- distance between needle positions
- thread tension -- how tightly thread is held during each poke
- travel speed -- how fast the arm moves between stitch positions
