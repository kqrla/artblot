# milestones -- wall arm (wet paint)

in order. each one is a gate for the next.
tufting milestones are in the rug-tufting branch, not here.

- [ ] arm can hold one brush and make a single mark on a vertical surface
- [ ] arm can re-dip at a fixed interval without smearing the palette
- [ ] arm can switch between two brushes cleanly
- [ ] calibration data collected for one brush + one paint + one surface
  (stroke length vs paint load vs mark quality)
- [ ] calibration library started, at least one medium documented end to end
- [ ] arm can accept a stroke plan from the engine and execute it with predictable results
- [ ] arm can complete a simple multi-stroke composition from engine output
