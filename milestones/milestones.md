# milestones -- embroidery

in order. each one is a gate for the next.

- [ ] machine can hold a needle and descend/ascend at a fixed x/y position
- [ ] machine follows a single stitch path (line of back stitches) without deviation
- [ ] machine completes a simple closed outline (heart, circle) end to end
- [ ] machine executes a satin stitch fill for a small region
- [ ] engine produces correct stitch paths from a simple design input
- [ ] one complete embroidered piece produced on dissolvable stabilizer, backing dissolved
- [ ] first sellable embroidered piece shipped through a real order
